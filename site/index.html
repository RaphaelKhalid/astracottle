How can we check an AI action?

Astra prepares a report. Astracottle checks it against your sharing rules before creating the file. It saves what Astra was given, what Astra proposed, and why the file was allowed or blocked.

We cannot read Astra’s mind. We can check its work. The current tool handles one small job: deciding which case records may go into a partner report.

The question behind the notebook

METHOD NOTE / 01

A public state is an intervention.

Ask an agent to commit the evidence it is using. Start a fresh session. Control which record and previous action it receives. Then observe whether its decision changes in the way the evidence requires.

The useful outcome is better oversight of consequential mistakes: unsupported completion claims, weakened tests, or records included in an unauthorized export.

What would count as evidence?

Compare records against an evidence-and-action baseline, isolate restart effects, and test relevant edits alongside paraphrases and irrelevant edits. Track task success as well as caught and missed violations.

Dependence on public text does not establish faithful access to a model’s private computation. Small fixtures do not establish frontier-model parity.

Publication policy

RELEASE BY ALLOWLIST

What is published

Synthetic task fixtures, experiment protocols, public model outputs, deterministic labels, token counts, latency, and analysis limitations. Planned, completed and incomplete studies are labeled separately.

What stays out

Credentials, private conversations, account usage and reset details, local file paths, session identifiers, and private reasoning. This website has no analytics, login, or model access. Theme preference is saved only in your browser.
